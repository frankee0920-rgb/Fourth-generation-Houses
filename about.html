METHODOLOGY

研究方法与数据结构

网站不是最终版式的终点，而是内容组织、交互浏览和人工确认层；同一套结构化数据可进入InDesign脚本自动重建原生版面。

研究模式保留来源、证据等级和待核实信息；汇报模式自动隐藏部分内部备注。
A

宽口径发现

以“第四代住宅”为主索引，并用空中庭院、立体生态住宅等词辅助发现线索。

B

严口径入选

只有空间、技术、运营和市场至少具备两项可靠证据的项目进入核心案例。

C

证据分级

A为官方或一手资料，B为多来源可交叉验证，C为宣传线索或待核实资料。

DATA PIPELINE

HTML / JSON / InDesign

content.json 保存案例、政策、问题和页面语义；HTML负责浏览器预览；InDesign UXP/JavaScript脚本读取HTML或JSON，在模板中创建原生文字框、图片框、表格和图注。

未来可继续增加 layout、图片路径、图注、来源、页型和InDesign样式映射字段。
